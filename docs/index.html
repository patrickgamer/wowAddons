The suite holds five independent Retail addons, each with its own slash command, and each can be enabled or disabled on its own. DuoAdventure only uses DuoSocial when DuoSocial is present; no addon needs another to run. No third-party runtime dependencies are required.

Versions and requirements

All five addons target Retail only (AllowLoadGameType mainline) at interface 120105. The documented target is Retail Midnight 12.1.5.70575. The addons have not been tested in-game on Windows or macOS; the behaviour below comes from source and docs, not live gameplay.

Installing and enabling

Use the same addon code on Windows and macOS. Install only into Retail, not Classic; enable any combination independently.

  1. Inspect and preserve existing AddOns folders and links; close WoW and back up unrelated addons.
  2. Install each chosen addon folder directly under Retail's Interface/AddOns, keeping its matching .toc and Lua files together. No extra nesting.
  3. Enable chosen addons in the character-selection AddOns list after restarting WoW.
  4. Use the commands below. Use /reload after later edits to discovered addons.

On Windows, use your actual Retail installation's Interface\AddOns; on macOS, use its Interface/AddOns. The project's intended whole-folder junction (Windows) or symlink (macOS) also works: AddOns points at the checkout. Inspect any existing link before changing it; never replace unrelated addons or link WTF. Source edits are live installation edits when linked. See the platform-specific link instructions (online).

Command notation: replace ID with an item or quest ID shown by the relevant panel, and Name-Realm with your companion’s full name locally. Where subcommands are abbreviated, prefix them with that section’s slash command. In alternatives such as standard|readable, choose one word; do not type the vertical bar. Brackets mean an optional argument, not literal text.

DuoBags

An inventory and supplies panel. Click the free-space badge or type /duobags. Search by name, class, item ID, keep or Companion. Keep rules protect items from this addon's own selling. Companion notes are personal notes only. Native bags, loot and confirmation windows stay as they are.

  • /duobags keep ID (or an item link) toggles a keep rule. /duobags partner ID toggles a Companion note.
  • /duobags loot shows this session's item receipts. /duobags clearloot clears that list.
  • /duobags auto reports the native auto-loot setting. auto on or auto off changes Blizzard's shared setting.
  1. Open a vendor on the Buy tab outside combat. Opening it sells nothing.
  2. Preview eligible grey stacks using the button or /duobags preview. Preview clears search.
  3. Sell ONE sells the first listed stack once, after a fresh item check.
  4. Repeat deliberately: each further stack needs a fresh preview and another click.

Bag changes, search edits and keep/Companion edits invalidate the preview. Equippable items, quest items, uncached/unknown items, locked items, embedded loot and protected items are excluded. Other addons' sales are not protected by these rules.

The loot log is session-only and may omit or undercount restricted/localised receipts; it is not a full ledger. Companion tags protect items from this addon’s sale, not a guarantee of tradeability. Auto-loot collects eligible items only after you open loot; native confirmations remain manual. The held auto-loot modifier reverses the native default. Treat its scope as shared unless the panel explicitly reports character scope; disable/reset does not restore the old value.

DuoUI

Two passive health bars: you, and your matched partner. They appear when enabled; /duoui prints help rather than toggling a panel. There is no class or level gate. Drag the display outside combat, or position it by number. The bars never target, heal or change Blizzard's frames. Keep Blizzard's own frames for numbers and interaction, and use Esc, Edit Mode to arrange them.

  • /duoui partner Name-Realm sets your partner. Target a party member and use /duoui select outside combat as an alternative. Empty partner clears it.
  • /duoui scale 1.2 (0.6 to 2), /duoui font 18 (10 to 28), /duoui face standard|readable, /duoui position -260 -120 (centre offsets, each from -2000 to 2000).
  • /duoui reset restores layouts and fonts. It keeps your partner name.

Solo profile

Your own position and scale; shows you.

Duo profile

Separate position and scale for any group, including raids; shows a matched partner.

Shared settings

Partner name, font size and font face.

Join or leave outside combat to configure each profile. Combat changes wait until combat ends. A roster change during combat clears the partner bar until a fresh match is safe.

DuoSupport

A reference panel for Evoker and Demon Hunter, chosen automatically from your class. It lists only spells you have learned, from your first playable level with no minimum-level gate. Unsupported classes have no reference module. The finite spell lists are not complete spellbooks; Demon Hunter coverage emphasises Havoc/Vengeance, not a complete Devourer catalogue. It does not read health, auras or cooldowns, and it never picks a spell or target for you. Each quick button casts one spell for one click.

  • /duosupport toggles the panel; /duosupport setup opens it. Drag it outside combat.
  • /duosupport partner Name-Realm or select sets the partner; spec havoc|vengeance chooses a planning profile (it does not change your real spec).
  • /duosupport priority Your preparation priorities and /duosupport agreement Your interrupt order save text for the selected planning profile within your detected class. Defaults are drafts, not confirmed agreements.
  • /duosupport bind ID your-key stores a reference note only. Real keys are set in Options, Keybindings.
  • /duosupport check roles|supplies|bindings toggles manual checkmarks. /duosupport page N (a positive page number) or the Next actions button changes the page of six buttons.

Configure and open before combat; protected updates wait and revalidate afterward. Keep native health and cooldown displays visible.

DuoSocial

A roster and notes panel. Type /duosocial outside combat to open it. Search names, roles, ranks, zones, favourites and your private notes. Invites and ready checks require an explicit action. This addon never sends ordinary chat or changes public/officer guild notes.

  • /duosocial partner Name-Realm (or select) sets your partner. invite and ready match the panel buttons Invite partner and Ready check; the game applies its own permission rules.
  • favourite Name-Realm toggles a favourite. note Name-Realm text and unnote Name-Realm manage a private note. offline shows cached offline guild members.
  • activity text saves the agreed plan. check roles|activity|preparation toggles manual checkmarks, which reset on reload.

Use exact full Name-Realm spelling for partner, favourites and notes. Favourites do not imply online presence. Solo play and play without a guild are supported. Refresh requests asynchronous roster data, which may be incomplete. Presentation pauses in combat. Invite requires native permission; Ready check requires leader/assistant status.

DuoAdventure

A quest planner for your accepted and logged quests. Pick Adventure to keep the game's order with full objective text, or Speed to sort accepted quests by pins, zone and distance. It never accepts, turns in, shares or abandons a quest for you. DuoAdventure progress sharing is off until you opt in; it is not native Party Sync and never starts, joins, answers or stops it.

  • /duoadventure mode adventure|speed switches modes. pin ID [rank] ranks a quest (1 to 999, lower first); pin ID alone toggles it. focus ID and unfocus set a manual focus.
  • note ID text, unnote ID and open ID (opens the native quest details where available).
  • social copies your focus into the DuoSocial activity field, only if DuoSocial is enabled.
  • share on|off (or the original sync on|off) sets progress-sharing consent, like the Progress sharing on/off button. share or sync alone requests an update, like Request progress.
  • native prints WoW's own Party Sync status. It only reads, and works in combat.
  1. Join an ordinary party. The prompt waits until combat ends.
  2. Both players opt in: check Share quest progress automatically, then Apply toggle; or use /duoadventure share on.
  3. Reports update on quest changes and every 30 seconds outside restrictions.
  4. Renew consent after leaving/rejoining or login/reload while grouped. The saved checkbox preference alone is not consent.

Keep off or closing the prompt leaves sharing off. Consent includes later joining party members. Peer reports expire after 120 seconds and clear on combat/group changes; they are not saved.

Speed order is ranked pins, completed quests, current-zone header, zone grouping, then available objective distance within a zone. It is a heuristic, not an optimal route or XP/hour guide. Search title, zone or ID. Hidden, unexposed or inaccessible log entries may be omitted; this is not a database of undiscovered quests.

Progress sharing versus native Party Sync

DuoAdventure progress sharing

Progress reports and catch-up advice only. Does not start, accept or stop native Party Sync, or alter native quest eligibility.

/duoadventure share off (or sync off) stops addon messages only. Request progress asks for fresh reports.

Panel line: Progress sharing (DuoAdventure addon reports, not WoW Party Sync).

WoW native Party Sync

A separate game session that can put quests on hold when the synced group does not meet requirements. Held quests can hide objectives and block completion.

Enabling DuoAdventure does not turn native Party Sync off. Both can run simultaneously.

Panel line: WoW Party Sync (native, read-only), showing active for you, a session in your group, a pending start or stop request, not active, or unknown. Unknown means WoW gave no usable answer; it is never shown as not active.

When WoW reports Party Sync active for you, DuoAdventure prints one chat notice, repeats it in the join prompt and explains the exit below. It prints again only after that session ends and a new one starts, or after a reload. The notice does not lift holds or show who started the session.

No addon in the suite starts, joins, answers, stops or supertracks Party Sync. None answers invitation, leave-party, convert-to-raid or ready-check confirmations, or clicks those dialogs. DuoSocial's Invite partner stays an explicit click; if Party Sync is running, WoW asks you to confirm.

Quest sharing and catch-up remain manual

  1. Use /duoadventure open ID with an ID shown in your panel, or open native quest details.
  2. If native Share is available and the other player needs the quest, choose Share yourself and wait for their acceptance.
  3. If sharing is unavailable, compare quest-giver/prerequisite requirements together. The other player may already have completed it or be ineligible.
  4. Before turning in, compare current reports and agree whether to wait or help. Same quest ID does not prove equal progress or phases.

Messages cannot align phases, replay quests, copy objective credit, bypass eligibility or automatically award completion. An unavailable Share button does not identify why a quest is on hold.

To leave native Party Sync deliberately: use Stop Party Sync at the bottom of Map & Quest Log and confirm. If you see only active status, the party member with the stop control must end it. This removes session holds, not other requirements; temporary replay quests disappear. It does not turn off progress sharing. The Native quest log button opens that log; it does not start or stop anything.

These distinctions follow the WOWA-9/14 investigation and Blizzard’s Party Sync explanation (online). They do not establish which requirement failed for any particular quest.

Transport and privacy limits

Both players need compatible V2 addons and consent in an ordinary party, not a raid. Reports include at most 200 exposed quests, completion flags, objective totals (up to 64), and up to six numeric progress pairs per quest. Combat/chat restrictions defer updates. Progress requests are spaced by at least 10 seconds; offline peers, packet loss or restrictions may mean no reply. A received snapshot is not proof of eligibility or matching phases.

Resetting and disabling

Disable any addon by unticking it in the AddOns list. To reset one addon completely: exit WoW, back up, then delete only that addon's saved file (and its .lua.bak) under WTF/Account/<account>/SavedVariables/ in that WoW installation. Saved files are DuoBags.lua, DuoUI.lua, DuoSupport.lua, DuoSocial.lua and DuoAdventure.lua. Resetting never changes Blizzard's native auto-loot, native Edit Mode layouts, or native keybindings. Deleting a saved file also removes your notes, favourites and rules for that addon, so back up WTF first.
